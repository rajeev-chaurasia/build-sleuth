Tired of waiting for documentation to be built?

You can quickly build documentation locally with just one command.

    cd DISTRIBUTION_FOLDER
    uv run --group docs build-docs

If you want to interactively work on your documentation you can add --autobuild flag.

    cd DISTRIBUTION_FOLDER
    uv run --group docs build-docs --autobuild

You can build several documentation packages together if they are modified together:
    uv run --group docs build-docs PACKAGE1 PACKAGE2

In the root of Airflow repo, you can build all packages together:
    uv run --group docs build-docs

You can also use other extra flags to iterate faster:
   --docs-only       - Only build documentation
   --spellcheck-only - Only perform spellchecking

You can list all packages you can build:

   --list-packages   - Shows the list of packages you can build

You can run clean build - refreshing inter-sphinx inventories or refresh airflow ones.

   --clean-build                 - Clean build files (without cleaning inventory cache)
   --clean-inventory-cache        - Clean inventory cache before fetching
   --refresh-airflow-inventories - Force refresh only airflow inventories (without cleaning build files or external inventories).

For more info:
   uv run build-docs --help
